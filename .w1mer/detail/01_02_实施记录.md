# 任务 02 实施记录（implementer）

基线：`9c6c9a3`；三个原子 commit：`7d36f2b`（抽象层）、`c66f296`（wtype）、
`981c9bd`（ydotool + 文档）。

## 实施内容

### A. 抽象层（7d36f2b，行为保持）

- `Backend` 基类：`type_text / type_char / press / focus_info / capabilities /
  resolvable / close`；`capabilities()` 固定字段 `name / can_focus_info /
  can_paste_mode / unicode / needs_remap / combos / per_char_delay / daemon`。
- 原 `Typer` 的 XTEST 方法体整体搬入 `X11Backend`（只加 `name`、`focus_info()`、
  `capabilities()`），`Typer` 退化为外观：持有 backend、`delay` 属性转发、
  `atexit` 注册幂等 `close()`。
- 模块级 `ctypes.CDLL` 改为 `_load_x11()` 惰性加载；argtypes/restype 声明随之
  移入。无 libX11 的机器可 `--help/--version`；`focused_window()` 调用前
  `_require_x11()`，未加载时抛 `BackendUnavailable` 而不是段错误。
- 异常层级：`Abort` → `BackendError` → `BackendUnavailable`；`main()` 的
  `except` 顺序保证环境缺失退 2、运行期失败退 1。
- `.dpy` 的 6 处外部引用改为 `focus_info()` / `target_label()`；删除了
  `main()` 里"无 DISPLAY 即退出 2"的硬检查，`--list-backends` 不受该检查影响。
- `multiline_risk()` 统一 X11 终端 / Wayland 全量的多行闸门；
  `warn_terminal_target` → `warn_multiline_target`。
- 测试接缝迁移：`test_typer.py` 里 `Typer(...)` → `X11Backend(...)`（3 处），
  `test_cli.py` 的 mock Typer 补上 `capabilities/focus_info`，原 62 条断言全部
  保留；`test_missing_display` 改为 `test_missing_backend_exits_2`（同一意图，
  由"缺 DISPLAY"变为"无任何可用后端"，还断言了安装提示）。

### B. wtype（c66f296）

- `_run(argv, *, capture_stdout=False)` 是唯一外部命令出口：`check=False`、
  `shell` 参数从不出现；测试可整体打桩。
- `WtypeBackend`：整串 `wtype -d <ms> -- <chunk>`；`_chunks()` 按 UTF-8 字节
  累加且按字符边界切分，单片 ≤ 32 KiB；组合键
  `-M ctrl -M shift -k v -m shift -m ctrl`；特殊键走 `SPECIAL` 的 keysym 名。
- 返回码非 0 抛 `BackendError`，stderr 命中协议特征时追加"合成器不支持
  virtual-keyboard / GNOME 用 ydotool"提示；`FileNotFoundError` 转
  `BackendUnavailable`。
- `detect_session()`：`XDG_SESSION_TYPE` 优先于 `DISPLAY`（XWayland 有
  DISPLAY 但 XTEST 到不了原生窗口）；`choose_backend()` auto 顺序：
  真 X11 → x11；Wayland → wtype。

### C. ydotool（981c9bd）

- evdev 键码表（字母/数字/符号/F1–F12/方向/Home/End/PgUp/PgDn/Insert/Delete/
  修饰键）；未知键抛 `Abort`，不猜码。
- `ydotool type --key-delay <ms> -- <chunk>`；组合键
  `ydotool key --key-delay <ms> 29:1 47:1 47:0 29:0`；大写单键自动加 shift。
- socket 探测顺序：`$YDOTOOL_SOCKET` → `$XDG_RUNTIME_DIR/.ydotool_socket`
  → `/tmp/.ydotool_socket`；都没有时明确提示 `ydotoold` 与 `/dev/uinput`
  权限，而不是只报"连接失败"。
- 非 ASCII 在进入 argv 之前就抛 `Abort`（消息含 "ydotool" 与 "非 ASCII"）；
  `capabilities()["unicode"] = False`。
- auto 扩展为 Wayland → wtype → ydotool（ydotool 还需 socket 可用）。
- 文档：SECURITY.md 更新"不执行 shell"的表述（固定 argv、不经 shell、
  X11 后端不 spawn 进程），新增后端选择/非 ASCII 拦截/惰性加载三项措施与
  Wayland 新风险（uinput 权限、mutter 不支持 virtual-keyboard）；README、
  README.en、CHANGELOG 同步。

## 遗留风险

- wtype 的 CJK 依赖合成器自带 keymap，部分 KDE 版本可能丢字；stderr 会透传。
- ydotool 只支持 ASCII，GNOME + 中文无可用后端（已显式拦截报错）。
- `--list-backends` 探测 wtype/ydotool 版本时会执行 `<tool> --version`；
  工具不存在时不会执行任何命令。
- 真机 Wayland（sway/KDE/GNOME）与注入类验收尚未执行（按纪律不实弹注入）。
