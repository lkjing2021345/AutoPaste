### 0′.4 安全复核（fail-closed 硬要求，§2.3 / §5.2 / §5.3 有实现细节）

3. **配置文件**：`O_NOFOLLOW` + 必须是本用户普通文件 + `mode & 0o022 == 0` + ≤64 KiB，

4. **安全开关不可配置**：`allow_root/allow_control/yes/no_restore_clipboard` 出现即 **2**；

## 0. 结论摘要（先看这 9 条）

1. **历史用 JSONL 持久化**：`~/.local/state/autopaste/history`（`XDG_STATE_HOME` 优先），
   一行一个 `{"v":1,"t":"..."}`，文件 0600、目录 0700，单条 ≤ 8 KiB / ≤ 200 行，
   最多 300 条、文件 ≤ 1 MiB；超限条目**不写入历史**（仍可用本会话的 `:r`），
   绝不写入"摘要占位"——历史里只放能原样重发的内容。
2. **多行历史用"折叠粘贴"回忆**：`LineEditor` 已有 `self.paste` 折叠显示机制，
   回忆多行条目时复用它（`[历史 N 字符 / M 行（回车重发，退格清除）]`），不改 `_render` 的行模型；
   粘贴/回忆态下打字被忽略，退格/Delete/Ctrl-U/Ctrl-W 先清除，避免静默丢内容。
3. **`:p` 完全复用 `_esc_preview()`**，只预览 `last`，额外显示字符数/行数/预计耗时/
   目标窗口/多行风险；**不发任何按键**。`:w <file>` 只写 `last`，拒绝符号链接与
   非普通文件，临时文件 + `os.replace` 原子落盘，0600。**不做 `:e`**。
4. **不引入 `logging`，用 ~45 行 `Log` 类**：级别 `quiet/normal/verbose` + 单一出口；
   `stdout` 只放"用户请求的数据"（dry-run、`--list-backends`、`--help`、`:p`、`:h`、`:t`、
   REPL 提示符与行编辑回显），其余诊断/警告/倒计时一律 `stderr`。`Log` **不得在 import 期
   缓存 `sys.stderr`**，否则 `redirect_stderr` 的测试会失效。
5. **`--quiet` 不得吞掉目标可视化**：倒计时从 0.1s 重绘降为**单行**
   `目标 [kitty] …｜3s 后可取消（任意键取消）`，仍轮询 stdin 可取消；
   多行风险提示、确认询问、错误信息一律保留。
6. **配置用手写"扁平 TOML 子集"解析器，所有 Python 版本同一条路径**
   （不用 `tomllib` 分支）：`requires-python >= 3.8` 没有 `tomllib`，本文件只有 5 个扁平键，
   子集本身是合法 TOML，将来换 `tomllib` 不会破坏已有文件。
7. **优先级 `命令行 > 配置 > 默认`**：`-d/--delay`、`--backend` 的 argparse 默认值改成 `None`
   （`-s` 已是 `None`），解析后用 `resolve_settings()` 填回，并记录**来源**（cli/config/default）
   供 `--verbose` 与 `:t` 使用。配置**只允许** `delay/sleep/backend/auto_enter/paste_mode`；
   `allow_root/allow_control/yes/no_restore_clipboard` 出现即**硬拒绝（退出 2）**。
8. **退出码固定 5 个**：`0` 成功、`1` 内容/数值校验失败、`2` 用法/配置/环境/安全拒绝
   （含 argparse 自身）、`3` 用户在安全确认处取消、`130` 中断；本任务把 `main()`
   的 13 条 `return` 与 4 个 `except` 收口成"一个 `except Abort` + `e.code`"。
9. **两处未捕获异常在本任务关闭**：`--repl` 非 tty 的 `termios.error` → 2；
   `open(file)`/`stdin.read()` 的 `OSError` → `Abort` → 1（与 `check_regular_file` 同一故障面
   不能有两个退出码）；`console_main()` 追加 `BrokenPipeError` → 0（`--list-backends | head`）。

## 2. 历史记录（04.1）

### 2.1 要不要持久化

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 仅会话内存 | 零隐私面、零 IO | 每次开新 REPL 都要重新粘贴 | 备选（`--no-history` 即此模式） |
| **持久化 JSONL（推荐）** | 跨会话可用，符合 shell 预期 | 会把**键盘/粘贴过的敏感文本**落到磁盘 | 采用，配 0600 + `--no-history` + SECURITY.md |
| 读 shell 的 `~/.bash_history` | 不用自己写 | 格式/时序/多 shell 冲突；还会混入无关命令 | 拒绝 |

隐私是真实风险（用户可能粘贴令牌/密码）。因此：

- 历史**默认开启**，但 `--no-history` 可完全关闭（**连读都不读、连目录都不建**）；
- 文件 **0600**、目录 **0700**；权限过宽时尝试收紧，**收紧失败就禁用历史**（fail-closed）；
- 历史内容**绝不进日志**（`--verbose` 只打印条数/路径）；
- SECURITY.md 明写："REPL 提交的文本会写入本地历史文件，敏感内容请用 `--no-history`"。

### 2.2 路径与格式

```python
def default_history_path(env=None) -> str | None:
    env = os.environ if env is None else env
    base = env.get("XDG_STATE_HOME") or ""
    if base and not os.path.isabs(base):
        return None                     # 相对路径会落到 cwd：fail-closed，退回仅内存
    if not base:
        home = env.get("HOME")
        if not home or not os.path.isabs(home):
            return None                 # 环境不完整：退化为"仅内存历史"
        base = os.path.join(home, ".local", "state")
    return os.path.join(base, "autopaste", "history")
```

文件格式：**JSONL，一行一条**（标准库 `json`）：

```
{"v": 1, "t": ":s 3"}
{"v": 1, "t": "echo hello"}
{"v": 1, "t": "line1\nline2\n"}
```

理由（对比两种备选）：

| 格式 | 多行/制表符 | 损坏容错 | 可读性 | 结论 |
|---|---|---|---|---|
| 转义单行（`\n` → `\\n`） | 需要自己写 unescape | 一行坏了只丢一条 | 差 | 不选 |
| **JSONL（推荐）** | `json.dumps` 天然处理 | 坏行跳过，其余可用 | 尚可 | 采用 |
| 整文件 JSON 数组 | 要整体重写 | 一个字节坏全丢 | 尚可 | 不选 |

- 写入：`os.open(path, O_WRONLY|O_CREAT|O_APPEND|O_NOFOLLOW, 0o600)`，`fstat` 校验后再写，
  单条一次 `os.write` 循环写完，立即 close。不做 `flock`（单用户 CLI，`O_APPEND` 单次小写入足够）。
- 读取：`O_RDONLY|O_NOFOLLOW`；逐行 `json.loads`，只接受 `{"v":1,"t":<str>}`，
  其余（坏 JSON、非 dict、`t` 非 str、超 8 KiB / 200 行）静默跳过，
  `--verbose` 下汇总一行"跳过 N 条损坏记录"。
- 压缩：启动时若文件 > 1 MiB，只读尾部 1 MiB（丢掉被切断的首行），重写"最后 300 条"到同目录
  临时文件（0600，`O_EXCL|O_NOFOLLOW`）再 `os.replace`；失败则放弃压缩、继续用内存历史（不阻塞 REPL）。
- 上限常量（放在 `MAX_COUNTDOWN` 之后）：

```python
HIST_MAX_ENTRIES      = 300        # 内存与文件都保留最后 300 条
HIST_MAX_ENTRY_BYTES  = 8 * 1024   # 单条 UTF-8 字节上限
HIST_MAX_ENTRY_LINES  = 200        # 单条行数上限
HIST_MAX_FILE_BYTES   = 1 << 20    # 超过则尾部截读 + 压缩
```

**为什么超限是"不存"而不是"存前 N 行"**：截断后的历史条目无法原样重发，
`↑` 拿到半截命令再回车会造成真实误操作；而"摘要占位"同样不可重发。
所以历史只保存**可原样重发**的内容；超大内容在本次会话仍可用 `:r` 重复。

### 2.3 `History` API（可直接照抄）

```python
class History:
    """REPL 历史。path=None 表示仅内存；任何安全/IO 问题都降级为"仅内存"并记原因。"""

    def __init__(self, path: str | None = None, *, euid=None):
        self.path = path
        self.entries: list[str] = []
        self.skipped = 0
        self.disabled_reason: str | None = None
        self._euid = os.geteuid() if euid is None else euid
        if path:
            try:
                self._load()
            except OSError as e:                 # 任何 IO 异常都不冒泡到 REPL
                self._disable(f"历史不可用，已退化为仅内存：{e}")

    def add(self, text: str) -> bool: ...
    # 1) 空白不存  2) UTF-8 <= 8 KiB 且 行数 <= 200
    # 3) 与当前最后一条相同 -> 不重复存（相邻去重）
    # 4) append + 裁到 300；path 且未禁用时 _append 一行
```

内部（**全部 fail-closed**，任一步不满足只禁用、不"尽力写"）。

> 若按 §8 的顺序先做 04.1（`Log` 尚未落地），把下面的 `LOG.warn(...)` 先写成
> `sys.stderr.write("⚠ " + msg + "\n")`，04.3 再一次性替换；若四个子任务合成一个 commit，
> 直接用 `LOG`。

```python
    def _disable(self, why):
        self.disabled_reason = why
        LOG.warn(why)

    def _check_dir(self, d) -> bool:
        st = os.lstat(d)                     # 可能抛 OSError -> 调用方按 False 处理
        if not stat.S_ISDIR(st.st_mode):  return False      # lstat 下符号链接不是 dir
        if st.st_uid != self._euid:       return False
        if stat.S_IMODE(st.st_mode) & 0o022:
            try:
                os.chmod(d, 0o700)
            except OSError:
                return False
        return True
```

- `_load()`：目录不存在 → 直接返回（首次 `add()` 时才建，`--no-history`/只读会话不建目录）；
  目录存在但 `_check_dir` 失败 → 禁用；`O_NOFOLLOW` 打开失败（`ELOOP`/`EACCES`）→ 禁用；
  `fstat` 非普通文件 / `st_uid != euid` → 禁用；`mode & 0o077` → `os.fchmod(fd, 0o600)`，
  失败则禁用；>1 MiB → 尾部截读并置 `compact=True`；解析后若 `compact` 调 `_compact()`。
- `_append(text)`：`os.makedirs(dir, 0o700, exist_ok=True)` → `_check_dir` → `O_NOFOLLOW|O_APPEND|O_CREAT`
  → `fstat` 校验 → `os.fchmod(fd, 0o600)` → `os.write` 循环；任何 `OSError` → 禁用。
- `_compact()`：同目录 `.<name>.autopaste-<pid>.tmp`（`O_CREAT|O_EXCL|O_NOFOLLOW, 0o600`）
  → 写最后 300 条 → `os.replace`；异常则删临时文件并保留内存历史。

### 2.4 增删规则

- **命令（`:s 3` 等）也进历史**（与 shell 一致）；`↑` 能找回上一条命令，`:q` 也会留下一条，无害。
- **普通文本在 `validate_payload()` 通过之后才 `add()`**：含控制字符的无效内容不进历史。
- `:f <file>` 只把**命令行本身**写入历史，不写文件正文（正文可能很大）。
- `:r` / 倒计时取消：命令字符串已进历史；被重复的正文不会重复入历史（`add()` 只在提交时调用）。
- 编辑历史行不回写（回车提交时才作为新条目 `add()`，相邻去重会吸收"原样重发"的情况）。

### 2.5 编辑器语义（关键细节）

`LineEditor.__init__(self, fd, history=None)`（**保持 `fd` 是唯一位置参数**，
现有 `tests/test_lineeditor.py:feed()` 不受影响）；`history` 是 list-like
（`History.entries` 或测试里的普通 list）。每次 `read()` 重置导航状态：

```python
        self.hist_i = len(self.history)     # 指向"新行"（one past end）
        self.hist_draft = None              # 首次↑时保存的当前行
        self.hist_prefix = None             # 首次↑时捕获的前缀（None=未进入历史）
        self.paste_origin = "paste"         # "paste" | "history"
```

- **↑（`ESC [ A` / `ESC O A`，以及 `Ctrl-P 0x10`）**
  1. 若 `paste is not None and paste_origin != "history"`：忽略（已有一份待提交的大内容，先退格清除）。
  2. 若 `hist_prefix is None`：`hist_prefix = "".join(self.buf)`，`hist_draft = 同值`。
  3. 从 `hist_i-1` 往前找第一条 `text.startswith(hist_prefix)` 的条目；找不到：不动。
  4. 命中则 `hist_i = j` 并装载。
- **↓（`ESC [ B` / `ESC O B`，以及 `Ctrl-N 0x0E`）**
  1. `paste_origin == "history"` 时仍允许继续往下翻（与 ↑ 对称）。
  2. 从 `hist_i+1` 往后找第一条匹配前缀的条目；找到则装载。
  3. 已经没有更**新**的匹配项：恢复 `hist_draft`，`hist_i = len(history)`，
     `hist_prefix = hist_draft = None`，下次↑重新捕获前缀。
- **装载**：

  ```python
  def _load_text(self, text, origin):
      if "\n" in text:
          self.paste, self.paste_origin = text, origin
          self.buf, self.pos = [], 0
      else:
          self.buf, self.pos = list(text), len(text)
          self.paste, self.paste_origin = None, "paste"
  ```

  多行条目**不做**"存进 buf 再渲染"——`_render()` 的宽度/光标模型不支持内嵌换行
  （`_width("\n")` 会当 1 列），复用 `self.paste` 的折叠标签最稳。
- **前缀搜索**：**首次按↑时行内的内容就是前缀**；空行时等价于普通历史。
  前缀在本次 `read()` 内固定，编辑历史行不会改变前缀。
- **落点**：`[A/OA`、`[B/OB` 加在现有 `if seq == "[3~"` 之后；
  `0x10/0x0E` 必须加在 `if c < 0x20: continue`（1152）**之前**，否则会被当成未知控制字符吞掉。
- **粘贴/回忆态下的输入**（现状是"字符塞进 buf 但回车提交 paste"，等于静默丢字）：
  - 可打印字符：**忽略**（`if self.paste is not None: continue`，放在 `c < 0x20` 分支之后）；
  - 退格（`0x7F/0x08`）/ Delete：先清除 `paste`（现有逻辑已覆盖）；
  - `Ctrl-U(0x15)`：清 `buf` 且清 `paste`；
  - `Ctrl-W(0x17)`：若 `paste` 存在且 `buf` 为空，先清 `paste` 并 `continue`。
- **显示**：

  ```python
  label = "历史" if self.paste_origin == "history" else "已粘贴"
  hint  = "回车重发，退格清除" if self.paste_origin == "history" else "退格清除"
  display = f"[{label} {len(self.paste)} 字符 / {nlines} 行（{hint}）]"
  ```

  必须保留子串 `已粘贴`（`test_paste_preview_not_in_payload` 依赖它）。

### 2.6 可测性

历史路径全部通过参数注入（`History(path=..., euid=...)`、`default_history_path(env=...)`），
测试不需要真实 HOME、真实 tty；上下键用现有 `tests/support.editor_input()` 把 `\x1b[A`

### 3.2 `:w <file>`

```python
elif name == "w":
    _cmd_save(arg, last)        # 失败抛 Abort（code=1），由 REPL 的 except 打印"已拦截"
```

安全规则（写死，测试覆盖）：

1. `arg` 为空 → `Abort("用法: :w <文件>")`。
2. `last is None` → `Abort("还没有可保存的内容")`。
3. `os.path.expanduser(arg)`；允许路径里有空格（`cmd.partition(" ")` 已把整段作为 arg）。
   末尾是 `/` 或 basename 为空 → 拒绝。
4. `os.lstat(path)`：
   - 存在且**不是普通文件**（符号链接/目录/FIFO/设备）→ 拒绝；
   - 符号链接**一律拒绝**（不做"跟随到你指定文件"的猜测）；
   - 存在且是普通文件 → 允许覆盖（用户显式命令），写后提示 `已覆盖 <path>`。
5. **不限制在 cwd**：这是用户自己的机器；父目录是符号链接则接受（等价于 shell 的 `>`）。
6. 原子写：同目录 `.<name>.autopaste-<pid>.tmp`，
   `os.open(..., O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW, 0o600)` → `os.write` **循环**写 UTF-8
   → `try: os.fsync(fd) except OSError: pass` → close → `os.replace(tmp, path)`。
   任何异常：`os.unlink(tmp)` 尽力清理，**原文件保持不变**。
   （`os.replace` 作用在目录项上，所以即使 `path` 在 lstat 之后被换成符号链接，也只会替换链接本身，
   不会写穿目标——这是选 `replace` 而不是 `open(path,"w")` 的第二个理由。）
7. 内容上限：`last` 已经过 `validate_payload`（≤1 MiB），无需另设。
8. 不自动补结尾换行（忠实保存）。
9. 权限 **0600**（内容可能敏感）；覆盖已有文件会把权限变成 0600——文档写明。
10. 成功回执走 `LOG.info`：`已保存 <path>（N 字符 / M 行，0600）`。

### 3.3 要不要 `:e`（调 `$EDITOR`）

**不做**。理由：需要临时退出 cbreak、`subprocess` 启动 `$EDITOR`（还要 `shlex.split`），
约 40–60 行 + 一组新测试，收益与 `:w` → 外部编辑 → `:f` 相同；且 `$EDITOR` 是环境变量驱动的
命令执行面，与 SECURITY.md "不执行 shell" 越走越远。若以后要做，独立任务、固定 argv、不进 shell。

## 4. 日志出口与 `--verbose/--quiet`（04.3）

### 4.1 结论：不用 `logging`

| 方案 | 评价 |
|---|---|
| `logging` + 两个 Handler | 需要 level/handler/formatter/`lastResort` 一套心智；`redirect_stderr` 下还依赖 `StreamHandler` 绑定的流 |
| **自写 ~45 行 `Log`（推荐）** | 级别 3 档、格式固定、流在写时解析、测试可直接替换；零依赖 |
| 继续散落 `sys.stdout.write` | 无法实现 `--quiet`，错误与数据混流 |

```python
class Log:
    QUIET, NORMAL, VERBOSE = 0, 1, 2
    def __init__(self, level=NORMAL, err=None):
        self.level, self._err = level, err
    def _stream(self):
        return self._err if self._err is not None else sys.stderr   # 必须惰性
    def info(self, msg):    # normal+；REPL 状态、banner、bye、回执
    def detail(self, msg):  # verbose only；配置来源/后端理由/耗时/历史统计
    def warn(self, msg):    # normal+；多行风险、恢复失败、历史权限/禁用
    def error(self, msg):   # 永远；被拦截/环境错误/配置错误

LOG = Log()

def set_log(level: int) -> None:
    LOG.level = level        # 原地改，保证被 mock.patch.object(autopaste, "LOG") 的实例也生效
```

`main()` 在 `parse_args` 之后**立刻** `set_log(...)`（早于 root 闸门与配置错误）。
测试里 `mock.patch.object(autopaste, "LOG", autopaste.Log(..., err=StringIO()))`。

### 4.2 流的分工（唯一契约）

- **stdout**：只有"用户明确请求的数据"——`--dry-run` 报告、`--list-backends`、`--help`、
  `:h`、`:t`、`:p`、REPL 提示符与行编辑回显（`LineEditor._w`）。
- **stderr**：banner、`bye`、`:s/:d/:nl` 回执、`已拦截`、警告、倒计时、`--verbose` 诊断、
  `--quiet` 下唯一一行倒计时摘要。
- **永远不打印 payload 正文**（`--verbose` 也不行）：只打 `len()`、行数、转义预览。

### 4.3 `--verbose` 输出什么（有界、够排障）

- **禁止安全开关进配置**：出现即 `ConfigError`（退出 2），文案：
  `配置不允许设置 allow_root（安全相关选项必须显式命令行指定）`。
  不静默忽略——用户会误以为配置生效。**`key.startswith("allow")` 也按禁止处理**。
- **未知键**：`LOG.warn("未知配置项 x，已忽略")`，继续运行（为未来键留前向兼容）。
- 值校验在 `load_config()` 内完成，失败一律 `ConfigError`（2）；`backend` 只接受枚举；
  `paste_mode` 在 03 未合入时按未知键警告（不要假装支持）。
- `bool` 只接受真正的 `true/false`（`0/1` → 错误），避免"`paste_mode = 1` 看起来生效了"。

### 5.3 加载与优先级

```python
class Config:
    __slots__ = ("delay", "sleep", "backend", "auto_enter", "paste_mode", "path")

class ConfigError(Abort):
    code = 2          # 配置属于运行环境/安全默认值

def default_config_path(env=None) -> str | None: ...   # XDG_CONFIG_HOME（须绝对）否则 ~/.config

def load_config(path=None, *, env=None, euid=None) -> Config | None:
    """path 为 None -> 默认路径；显式路径不存在 -> ConfigError。"""

def parse_config_text(text, *, path="<config>") -> Config: ...   # 纯函数，测试主力

def resolve_settings(args, cfg) -> dict[str, tuple]:
    """命令行 > 配置 > 默认；返回 {名字: (值, 来源)}，来源 ∈ {"cli","config","default"}。"""
```

`load_config` 的 fail-closed 检查（顺序固定）：

```python
    fd = os.open(path, os.O_RDONLY | os.O_NOFOLLOW)   # FileNotFoundError -> 默认路径返回 None
    st = os.fstat(fd)
    if not stat.S_ISREG(st.st_mode):             raise ConfigError("不是普通文件")
    if st.st_uid != euid:                        raise ConfigError("不属于当前用户")
    if stat.S_IMODE(st.st_mode) & 0o022:         raise ConfigError("对组/其他用户可写")
    if st.st_size > CONFIG_MAX_BYTES:            raise ConfigError("过大")
    raw = fd read CONFIG_MAX_BYTES
    text = raw.decode("utf-8")                   # UnicodeDecodeError -> ConfigError
```

- 文件不存在：**默认路径**下返回 `None`（用默认值）；`--config <显式路径>` 不存在 → `ConfigError`。
- **默认路径上的可疑文件（属主不对/组可写/符号链接）→ 2，不回退到默认值**：
  静默降级会把被篡改的机器伪装成正常。
- `build_parser()` 的改动：

  ```python
  ap.add_argument("-d", "--delay", type=float, default=None, help="……默认 0.008（可被配置文件覆盖）")
  ap.add_argument("--backend", choices=(...), default=None, ...)
  g = ap.add_mutually_exclusive_group()
  g.add_argument("-v", "--verbose", action="store_true")
  g.add_argument("-q", "--quiet", action="store_true")
  ap.add_argument("--config", default=None, metavar="PATH")
  ap.add_argument("--no-config", action="store_true")
  ap.add_argument("--no-history", action="store_true")
  ```

- `main()` 合并与校验（**校验留在值来源处**，这样退出码天然正确）：

  ```python
  R = resolve_settings(args, cfg)
  delay = (_num(str(R["delay"][0]), 0.0, MAX_DELAY, "字符间隔")
           if R["delay"][1] == "cli" else R["delay"][0])      # 配置值已在 load_config 校验
  sleep = (None if R["sleep"][0] is None else
           (_num(str(R["sleep"][0]), 0.0, MAX_COUNTDOWN, "倒计时")
            if R["sleep"][1] == "cli" else R["sleep"][0]))
  ```
- `sleep` 的 `None` 表示"按模式默认"：CLI → `0.0`，REPL → `2.0`（保持现状）；
  配置里写了 `sleep` 则两种模式**都**用该值（README 写清）。
- `paste_mode`（03 合入后）：`cli or cfg` —— `--paste-mode` 只能打开，配置只能提供默认打开；
  配置文件**不能**关闭也不是"更严格"的开关。
- `--list-backends` 在加载配置**之前**处理，输出不受配置影响（它描述的是 auto 规则）。
- **会破坏 `tests/test_cli.py:test_defaults` 的一条断言**（`args.delay == 0.008`）：
  同步改成 `assertIsNone(args.delay)`、`assertIsNone(args.backend)`，并新增
  `test_resolve_settings_prefers_cli_over_config`。
- REPL 的 `:s/:d/:nl/:w` 只改本次会话，**永不回写配置文件**；
- `:t` 增加来源提示：`字符间隔=0.008s（默认）  倒计时=2.0s（配置）`。

### 5.4 生效顺序（`main` 前段，红线不可换）

```
parse_args → set_log(level) → --list-backends? → root 闸门
→ load_config(--no-config? None) → resolve_settings → CLI 值校验
→ interactive? → REPL tty 预检 → Typer 构造 → 其余
```

配置错误发生在 **root 闸门之后、Typer 构造之前**，绝不在读配置时产生任何副作用。
root 闸门必须留在 `load_config` 之前（见 §0′.4-5）。

### 6.4 `Abort.code` 与 03 的衔接
