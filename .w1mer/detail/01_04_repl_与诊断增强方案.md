## 0. 结论摘要（先看这 8 条）

1. **历史用 JSONL 持久化**：`~/.local/state/autopaste/history`（`XDG_STATE_HOME` 优先），
   一行一个 `{"v":1,"t":"..."}`，文件 0600、目录 0700，单条 ≤ 8 KiB / ≤ 200 行，
   最多 300 条、文件 ≤ 1 MiB；超限条目**不写入历史**（仍可用本会话的 `:r`），
   绝不写入"摘要占位"——历史里只放能原样重发的内容。
2. **多行历史用"折叠粘贴"回忆**：`LineEditor` 已有 `self.paste` 折叠显示机制，
   回忆多行条目时复用它（`[历史 N 字符 / M 行]`），不改 `_render` 的行模型；
   粘贴/回忆态下打字被忽略，退格/Delete/Ctrl-U 先清除，避免静默丢内容。
3. **`:p` 完全复用 `_esc_preview()`**，只预览 `last`，额外显示字符数/行数/预计耗时/
   目标窗口/多行风险；**不发任何按键**。`:w <file>` 只写 `last`，拒绝符号链接与
   非普通文件，临时文件 + `os.replace` 原子落盘，0600。**不做 `:e`**（引入 `$EDITOR`
   执行面不值当，`:w` + 外部编辑 + `:f` 已覆盖）。
4. **不引入 `logging`，用 ~40 行 `Log` 类**：级别 `quiet/normal/verbose` + 单一出口；
   `stdout` 只放"用户请求的数据"（dry-run、`--list-backends`、`:p`、`:h`、`:t`、
   REPL 提示符），其余诊断/警告/倒计时一律 `stderr`。`Log` **不得在 import 期缓存
   `sys.stderr`**，否则 `redirect_stderr` 的测试会失效。
5. **`--quiet` 不得吞掉目标可视化**：倒计时从 0.1s 重绘降为**单行**
   `目标 [kitty] …｜3s 后可取消（任意键取消）`，仍轮询 stdin 可取消；
   多行风险提示、确认询问、错误信息一律保留。
6. **配置用手写"扁平 TOML 子集"解析器，所有 Python 版本同一条路径**
   （不用 `tomllib` 分支）：`Python 3.8` 没有 `tomllib`，而本文件只有 5 个扁平键，
   同一条严格子集（注释 / `key = value` / 可选 `[autopaste]` 头）在 3.8–3.13 行为
   完全一致；子集本身是合法 TOML，将来换 `tomllib` 不会破坏已有文件。
7. **优先级 `命令行 > 配置 > 默认`**，实现方式是把 `-d/--delay`、`-s/--sleep`、
   `--backend` 的 argparse 默认值改成 `None`，解析后用 `_apply_config()` 填回。
   配置**只允许** `delay/sleep/backend/auto_enter/paste_mode`；`allow_root/allow_control/
   yes/no_restore_clipboard` 出现即**硬拒绝（退出 2）**，不静默忽略。
8. **退出码固定 5 个**：`0` 成功、`1` 内容/参数值校验失败、`2` 用法/环境/配置/安全
   拒绝（含 argparse 自身）、`3` 用户在安全确认处取消、`130` 中断/倒计时取消。
   当前 `main()` 的 17 条返回路径已逐条核对，只有 "REPL 非 tty" 与若干 `OSError`
   是未捕获缺口（见 §6），随本任务统一。

## 2. 历史记录（04.1）

### 2.1 要不要持久化

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 仅会话内存 | 零隐私面、零 IO | 每次开新 REPL 都要重新粘贴 | 备选 |
| **持久化 JSONL（推荐）** | 跨会话可用，符合 shell 预期 | 会把**键盘/粘贴过的敏感文本**落到磁盘 | 采用，配 0600 + `--no-history` + SECURITY.md 说明 |
| 读 shell 的 `~/.bash_history` | 不用自己写 | 格式/时序/多 shell 冲突；还会混入无关命令 | 拒绝 |

隐私是真实风险（用户可能粘贴令牌/密码）。因此：

- 历史**默认开启**，但 `--no-history` 可完全关闭（连读都不读）；
- 文件 **0600**、目录 **0700**；已存在但权限过宽时先 `chmod 0600` 并打印一行警告；
- 历史内容**绝不进日志**（`--verbose` 只打印条数/路径）；
- SECURITY.md 明写："REPL 提交的文本会写入本地历史文件，敏感内容请用 `--no-history`"。

### 2.2 路径与格式

```python
def default_history_path(env=None) -> str | None:
    env = os.environ if env is None else env
    base = env.get("XDG_STATE_HOME")
    if not base:
        home = env.get("HOME")
        if not home:
            return None                 # 环境不完整：退化为"仅内存历史"
        base = os.path.join(home, ".local", "state")
    return os.path.join(base, "autopaste", "history")
```

文件格式：**JSONL，一行一条**（用标准库 `json`，不需要第三方）：

```
{"v": 1, "t": ":s 3"}
{"v": 1, "t": "echo hello"}
{"v": 1, "t": "line1\nline2\n"}
```

理由（对比两种备选）：

| 格式 | 多行/制表符 | 损坏容错 | 可读性 | 结论 |
|---|---|---|---|---|
| 转义单行（`\n` → `\\n`） | 需要自己写 unescape | 一行坏了只丢一条 | 差 | 不选 |
| **JSONL（推荐）** | `json.dumps` 天然处理 | 坏行跳过，其余可用 | 尚可 | 采用 |
| 整文件 JSON 数组 | 要整体重写 | 一个字节坏全丢 | 尚可 | 不选 |

- 写入：`os.open(path, O_WRONLY|O_CREAT|O_APPEND, 0o600)`，单条 `os.write`，立即 close。
  不做 `flock`（单用户 CLI，`O_APPEND` 单次小写入足够；并发 REPL 最多交错整行）。
- 读取：`open(..., encoding="utf-8", errors="replace")`；逐行 `json.loads`，
  只接受 `{"v":1,"t":<str>}`，其余（坏 JSON、非 dict、`t` 非 str）静默跳过，
  `--verbose` 下汇总一行"跳过 N 条损坏记录"。
- 压缩：启动时若文件 > 1 MiB，重写"最后 300 条"到同目录临时文件（0600）再
  `os.replace`；失败则放弃压缩、继续使用内存历史（不阻塞 REPL）。
- 上限常量：

```python
HIST_MAX_ENTRIES      = 300        # 内存与文件都保留最后 300 条
HIST_MAX_ENTRY_BYTES  = 8 * 1024   # 单条 UTF-8 字节上限
HIST_MAX_ENTRY_LINES  = 200        # 单条行数上限
HIST_MAX_FILE_BYTES   = 1 << 20    # 触发压缩
```

**为什么超限是"不存"而不是"存前 N 行"**：截断后的历史条目无法原样重发，
`↑` 拿到半截命令再回车会造成真实误操作；而"摘要占位"同样不可重发。
所以历史只保存**可原样重发**的内容；超大内容在本次会话仍可用 `:r` 重复。
（`MAX_PAYLOAD` 是 1 MiB，正常 8 KiB 以内的小段粘贴都会进历史。）

### 2.3 增删规则

```python
class History:
    def __init__(self, path=None, entries=None): ...
    def add(self, text: str) -> bool:
        # 1) 空白不存
        # 2) UTF-8 <= 8 KiB 且 行数 <= 200
        # 3) 与当前最后一条相同 -> 不重复存（相邻去重）
        # 4) 追加 entries，裁到 300；有 path 则 append 一行
```

- **命令（`:s 3` 等）也进历史**（与 shell 一致），便于↑找回上一条命令；
  `:q` 也会留下一条，无害。
- **普通文本在 `validate_payload()` 通过之后才 `add()`**：含控制字符的无效内容
  不进入历史，避免被反复回忆重发。
- `:f <file>` 只把**命令行本身**写入历史，不写文件正文（正文可能很大）。
- `:r` / 倒计时取消：命令字符串已进历史；被重复的正文不会重复入历史。

### 2.4 编辑器语义（关键细节）

`LineEditor.__init__(self, fd, history=None)`，`history` 是 list-like（`History.entries`
或测试里的普通 list）。每次 `read()` 重置导航状态：

```python
self.hist_i = len(self.history)     # 指向"新行"（one past end）
self.hist_draft = None              # 首次↑时保存的当前行
self.hist_prefix = None             # 首次↑时捕获的前缀（None=未进入历史）
self.paste_origin = "paste"         # "paste" | "history" | "draft"
```

- **↑（`ESC [ A` / `ESC O A`）**
  1. 若 `paste is not None`：忽略（当前已有一份待提交的大内容，先退格清除）。
  2. 若 `hist_prefix is None`：`hist_prefix = "".join(buf)`，`hist_draft = 同值`。
  3. 从 `hist_i-1` 往前找第一条 `text.startswith(hist_prefix)` 的条目；找不到：不动。
  4. 命中则 `hist_i = j` 并装载（见下）。
- **↓（`ESC [ B` / `ESC O B`）**
  1. `paste is not None` 且来源是 history：忽略（同上）。
  2. 从 `hist_i+1` 往后找第一条匹配前缀的条目；找到则装载。
  3. 已经没有更**新**的匹配项：恢复 `hist_draft`（草稿），`hist_i = len(history)`，
     `hist_prefix = None`，下次↑重新捕获前缀。
- **装载**：
  ```python
  def _load_text(self, text, origin):
      if "\n" in text:
          self.paste, self.paste_origin = text, origin   # 复用折叠显示
          self.buf, self.pos = [], 0
      else:
          self.buf, self.pos = list(text), len(text)
          self.paste, self.paste_origin = None, "paste"
  ```
  多行条目**不做**"存进 buf 再渲染"——现有 `_render()` 的宽度/光标模型不支持
  内嵌换行（`_width("\n")` 会当 1 列），直接复用 `self.paste` 的折叠标签最稳。
- **前缀搜索**：采用（约 15 行）。规则：**首次按↑时行内的内容就是前缀**；
  空行时等价于普通历史。前缀在本次 `read()` 内固定，编辑历史行不会改变前缀。
  这既满足"输入 `:s` 后↑只翻 `:s` 开头的命令"，也不会引入增量搜索状态机。
- **编辑历史行**：只改 `buf`，**不写回历史**（回车提交时才作为新条目 `add()`）；
  若还与上一条相同则被相邻去重丢掉。这是 readline 的常见行为，文档写清即可。
- **粘贴/回忆态下的输入**：
  - 可打印字符：**忽略**（当前实现会把它塞进 `buf`，但回车时提交的是 `paste`，
    等于静默丢字；明确忽略并保留折叠提示更诚实）。
  - 退格（`0x7F/0x08`）/ Delete/`Ctrl-U`：先清除 `paste`（随后的一次退格才删 `buf`），
    与现有 `test_backspace_after_paste_clears_paste` 兼容。
  - `Ctrl-W`：若 `paste` 存在且 `buf` 为空，也先清除 `paste`（否则会删不到东西）。
- **补充键位**：`Ctrl-P(0x10)`/`Ctrl-N(0x0E)` 作为↑/↓别名（2 行，readline 肌肉记忆）。
- **显示**：`_render` 中折叠标签按来源区分：
  `[已粘贴 1234 字符 / 30 行（退格清除）]` 与 `[历史 1234 字符 / 30 行（回车重发，退格清除）]`。

### 2.5 可测性

历史路径全部通过参数注入（`History(path=...)`、`default_history_path(env=...)`），
测试不需要真实 HOME、真实 tty；编辑器的上下键用现有 `tests/support.editor_input()`

## 3. `:p` 预览 / `:w` 保存（04.2）

### 3.1 `:p`（复用 `_esc_preview`）

```python
elif name == "p":
    _cmd_preview(typer, cfg, last)      # 不发送任何东西
```

输出（stdout，因为这是用户显式请求的数据）：

```
  预览（123 字符 / 3 行，预计 1.0s，未发送）:
  echo "a\nb"  ...
  目标: [kitty] ~/src
  ⚠ 目标是终端 …：多行文本会被逐行执行（共 3 行）。
```

- 正文 `_esc_preview(last)`（默认 400 字符，已把 `\n`→`\\n`、`\t`→`\\t`、
  C0/DEL→`\xNN`），与 `--dry-run` 的转义规则**完全同一实现**，不另写。
- `last is None` → `  还没有可预览的内容（先输入一段或 :f <文件>）`。
- 行数用 `last.count("\n") + (0 if last.endswith("\n") else 1)`（与 REPL 现有语义一致）。
- 预计耗时 `len(last) * cfg.delay`，超过 60s 时提示"建议用 `--paste-mode`（03 合入后）"。
- `multiline_risk()` 有值就顺带打印（**只看不发**），让 `:p` 也能承担"看一眼再决定"的作用。
- 不做 `:p <n>`（历史第 n 条）：04.1 刚落地时编号语义容易和 `↑` 混淆，留到以后。

### 3.2 `:w <file>`

```python
elif name == "w":
    _cmd_save(arg, last)        # 失败抛 Abort，由 REPL 的 except 打印"已拦截"
```

安全规则（写死，测试覆盖）：

1. `arg` 为空 → `Abort("用法: :w <文件>")`。
2. `os.path.expanduser(arg)`；允许路径里有空格（`cmd.partition(" ")` 已把整段作为 arg）。
3. `os.lstat(path)`：
   - 存在且**不是普通文件**（符号链接/目录/FIFO/设备）→ 拒绝；
   - 符号链接**一律拒绝**（不做"跟随到你指定文件"的猜测；这是最容易踩的坑）；
   - 存在且是普通文件 → 允许覆盖（用户显式命令），写前打印 `已覆盖 <path>`。
4. **不限制在 cwd**：这是用户自己的机器、自己的路径，强化限制只会让 `:w ~/notes/x`
   这类正常用法失效。真正的风险是"共享目录里的符号链接"，由第 3 条挡住；
   父目录若是符号链接则接受（等价于 shell 的 `>`）。
5. 原子写：同目录 `.<name>.autopaste-<pid>.tmp`，`os.open(..., O_WRONLY|O_CREAT|O_EXCL, 0o600)`
   → 写入 UTF-8 → close → `os.replace(tmp, path)`。失败时删除临时文件，**原文件保持不变**。
6. 内容上限：`last` 已经过 `validate_payload`（≤1 MiB），无需另设。
7. 不自动补结尾换行（忠实保存）；`--no-newline`/`:f` 的语义已在上游处理。
8. 权限 **0600**（内容可能敏感）；覆盖已有文件会把权限变成 0600——文档写明。

### 3.3 要不要 `:e`（调 `$EDITOR`）

**不做**。理由：

- 需要临时退出 cbreak、`termios.tcsetattr` 恢复、`subprocess` 启动 `$EDITOR`
  （还要 `shlex.split` 处理 `"code -w"` 这类值），再把结果读回编辑器——约 40–60 行
  + 一组新测试，收益与 `:w` → 外部编辑 → `:f` 相同；
- `$EDITOR` 是环境变量驱动的命令执行面，与 SECURITY.md "不执行 shell" 的表述
  越走越远（Wayland 后端已 exec，但那是固定 argv）；
- 若以后确实要，独立任务做，且必须 `shlex.split` + 固定 argv + 不进 shell。

## 4. 日志出口与 `--verbose/--quiet`（04.3）

### 4.1 结论：不用 `logging`

| 方案 | 评价 |
|---|---|
| `logging` + 两个 Handler | 需要 level/handler/formatter/`lastResort` 一套心智；`redirect_stderr` 下行为还依赖 `StreamHandler` 绑定的流；对单文件 CLI 过重 |
| **自写 ~40 行 `Log`（推荐）** | 级别 3 档、格式固定、流在写时解析、测试可直接替换；零依赖 |
| 继续散落 `sys.stdout.write` | 无法实现 `--quiet`，错误与数据混流 | 

```python
class Log:
    QUIET, NORMAL, VERBOSE = 0, 1, 2
    def __init__(self, level=NORMAL, err=None):
        self.level, self._err = level, err
    def _stream(self):
        return self._err if self._err is not None else sys.stderr   # 必须惰性
    def info(self, msg):    # normal+；REPL 状态、banner、bye
    def detail(self, msg):  # verbose only；配置来源/后端理由/耗时
    def warn(self, msg):    # normal+；多行风险、恢复失败、历史权限
    def error(self, msg):   # 永远；被拦截/环境错误
```

模块级 `LOG = Log()`；`main()` 在 `parse_args` 后立刻 `set_log(level)`。
测试里 `mock.patch.object(autopaste, "LOG", autopaste.Log(..., err=StringIO()))`。

### 4.2 流的分工（唯一契约）

- **stdout**：只有"用户明确请求的数据"——`--dry-run` 报告、`--list-backends`、
  `--help`、`:h`、`:t`、`:p`、REPL 的行编辑回显与提示符。
- **stderr**：banner、`bye`、`:s/:d/:nl` 的回执、`已拦截`、警告、倒计时、
  `--verbose` 诊断、`--quiet` 下唯一一行倒计时摘要。
- **永远不打印 payload 正文**（`--verbose` 也不行）：只打 `len()`、行数、转义预览。

这条分工顺带解决现有 REPL 的"错误写 stdout"问题；`test_cli` 只断言 dry-run 的
stdout，不受影响。

### 4.3 `--verbose` 输出什么（有界、够排障）

- 配置：`配置: /home/u/.config/autopaste/config.toml（3 项）` 或 `未找到，使用默认值`；
- 后端：`后端: x11（auto：真 X11 会话）` + 一行 capabilities（`name/can_focus_info/unicode/…`）；
- 生效参数：`delay=0.008（默认） sleep=2.0（配置） backend=auto（命令行）`；
- 收尾：`已发送 1234 字符 / 3 行，用时 9.9s（124.6 字/秒）`（CLI 与 REPL 提交都打）；
- 历史：`历史: /home/u/.local/state/autopaste/history（载入 42 条，跳过 1 条损坏）`；
- **禁止**：逐字符日志、payload 正文、读取到的文件内容。

### 4.4 `--quiet` 与倒计时（安全可视化不能丢）

`countdown(seconds, typer, cancelable=True)` 增加静默分支：

```python
if LOG.level == Log.QUIET:
    _stream_write(f"目标 {target}｜{left:g}s 后可取消（任意键取消）\n")
    # 仍然 select 轮询，可取消；不再 0.1s 重绘
```

- `--quiet` 抑制：banner、`:s/:d/:nl` 回执、`bye`、`--verbose` 信息、倒计时动画。
- `--quiet` **不抑制**：倒计时目标行（降级为一行）、多行风险警告、`_confirm()` 询问、
  `Abort`/`BackendError`/根拒绝等错误。
- `--ios` 无关。`-s 0` 时本来就没有倒计时（现有 `countdown` 在 `seconds <= 0`
  直接返回），因此 `--quiet -s 0` 不会显示目标——与现状一致，文档提示"要确认目标就别用 -s 0"。
- `--verbose` 与 `--quiet` 用 `argparse` 互斥组，同时给 → argparse 退出 2。

## 5. 配置文件（04.4）

### 5.1 3.8 兼容方案：三选一

| 方案 | 3.8 | 3.11+ | 行为一致性 | 代码量 | 结论 |
|---|---|---|---|---|---|
| `tomllib` 分支 + 手写回退 | 手写 | tomllib | 两套路径，边缘语法可能不同 | ~80 | 不选 |
| 改用 JSON（`config.json`） | ✓ | ✓ | 完美 | ~10 | 违背 ROADMAP 的 `config.toml` |
| **手写"扁平 TOML 子集"，所有版本同一路径** | ✓ | ✓ | 完美 | ~70 | **采用** |

子集语法（就是本程序需要的全部）：

```toml
# ~/.config/autopaste/config.toml
delay = 0.02          # 注释：float，0..5
sleep = 2.5           # float，0..3600；CLI 与 REPL 都生效
backend = "wtype"     # "auto" | "x11" | "wtype" | "ydotool"
auto_enter = false    # 仅 REPL
paste_mode = false    # 仅当 03 合入后生效
```

- 允许空行、`#`（行首/值后）注释、可选的单个 `[autopaste]` 段头（有/无都行）；
- 值只允许：双/单引号字符串、`true`/`false`、十进制整数/浮点；**拒绝数组、日期、
  多行字符串、`nan/inf`、嵌套表**，错误信息带 `path:行号`；
- 重复键 → 错误（TOML 语义）；`[其它段]` → 错误；
- 文件上限 64 KiB；`os.stat` 必须是普通文件、**属主是当前用户**、
  `mode & 0o022 == 0`（组/其他用户可写 → 拒绝，防止共享机器上被注入）；
- 文件不存在：**默认路径**下静默使用默认值；`--config <显式路径>` 不存在 → 错误 2。

### 5.2 键白名单与安全

```python
CONFIG_KEYS = {
    "delay":      ("float", 0.0, MAX_DELAY),
    "sleep":      ("float", 0.0, MAX_COUNTDOWN),
    "backend":    ("enum", ("auto", "x11", "wtype", "ydotool")),
    "auto_enter": ("bool", None, None),
    "paste_mode": ("bool", None, None),   # 03 合入后才加入；之前视为未知键
}
FORBIDDEN_KEYS = {"allow_root", "allow_control", "yes", "no_restore_clipboard"}
```

- **禁止安全开关进配置**：`allow_root/allow_control/yes/no_restore_clipboard`
  出现即 `ConfigError`（退出 2），文案：
  `配置不允许设置 allow_root（安全相关选项必须显式命令行指定）`。
  不静默忽略——用户会误以为配置生效。
- **未知键**：`LOG.warn` 一行（"未知配置项 x，已忽略"），继续运行——为未来键留前向兼容；
  但**若键以 `allow` 开头**仍按禁止处理（防手滑写 `allow-root`）。
- 值校验复用 `_num` 的边界语义；`backend` 只接受枚举；`paste_mode` 在 03 未合入时
  按未知键警告（不要假装支持）。

### 5.3 优先级实现（关键改动）

```python
# build_parser():
ap.add_argument("-d", "--delay", type=float, default=None, ...)
ap.add_argument("-s", "--sleep", type=float, default=None, ...)
ap.add_argument("--backend", choices=..., default=None, ...)
ap.add_argument("--config", default=None, metavar="PATH")
ap.add_argument("--no-config", action="store_true")
ap.add_argument("--no-history", action="store_true")

def resolve_settings(args, cfg):
    """命令行 > 配置 > 默认；返回 (delay, sleep, backend, auto_enter, paste_mode)。"""
    delay = args.delay if args.delay is not None else (cfg.delay if cfg else 0.008)
    sleep = args.sleep if args.sleep is not None else (cfg.sleep if cfg else None)
    backend = args.backend if args.backend is not None else (cfg.backend if cfg else "auto")
```

- `sleep` 的 `None` 表示"按模式默认"：CLI → `0.0`，REPL → `2.0`（保持现状）；
  配置里写了 `sleep` 则两种模式**都**用该值（这就是"默认 sleep"的含义，README 写清）。
- `-d` 的 help 文本改为"默认 0.008（可被配置文件覆盖）"；
- **会破坏现有 `test_defaults` 的三条断言**（`args.delay == 0.008` 等）：
  同步改成 `assertIsNone`，并在 `test_cli` 新增"解析后填充默认值"的用例；
- `--list-backends` 在加载配置**之前**处理，输出不受配置影响（它描述的是 auto 规则）；
- REPL 的 `:s/:d/:nl/:w` 只改本次会话，**永不回写配置文件**；
- `:t` 增加一行来源提示：`字符间隔=0.008s（默认）  倒计时=2.0s（配置）`。

### 5.4 生效顺序（`main` 前段）

```
parse_args → set_log(level) → --list-backends? → root 闸门
→ load_config(--no-config? None) → resolve_settings → 其余
```

配置错误发生在 root 闸门之后、Typer 构造之前，绝不在读配置时产生任何副作用。
