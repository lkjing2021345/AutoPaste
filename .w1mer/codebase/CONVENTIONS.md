# CONVENTIONS

- **语言**：代码注释、文档、提交信息一律中文（README 另有英文版）。
- **依赖红线**：不引入第三方包；新增能力优先用标准库 + ctypes。
- **安全默认**：默认拒绝 root、拒绝控制字符、拒绝 FIFO/设备、终端多行需确认；
  任何新特性不得放宽这些默认值，只能通过显式 flag 打开。
- **失败路径**：所有异常都要保证修饰键释放 + 键盘映射还原（`try/finally`）。
- **错误处理**：用户输入类错误抛 `Abort`，在 `main()` 统一转成中文提示 + 非零退出码；
  预期退出码：0 成功，1 参数/校验失败，2 环境/安全拒绝，3 用户取消安全确认，130 中断。
- **提交**：一个任务一个 commit，`type(scope): 中文摘要`，正文列要点；不 push（编排者统一推）。
- **测试**：不依赖真实 X11（用假后端/依赖注入），`python3 -m unittest discover -s tests`。
